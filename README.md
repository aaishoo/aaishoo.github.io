# faisholhakim.com

Personal site of Muhamad Faishol Hakim — DFIR & threat intelligence engineer.

Static, no build step. Served from GitHub Pages via the `CNAME` record.

| Path | Contents |
|------|----------|
| `index.html` | Profile: focus, experience, cases, projects, arsenal, certifications, competitions, contact |
| `blog/index.html` | Writing index with topic filters |
| `sitemap.xml` | Only lists pages that exist — add a post's URL here when the post ships |

Design tokens (palette, type scale, spacing) are declared in the `:root` block of each
page. All text/background pairs are verified at WCAG AA (4.5:1) or better.
